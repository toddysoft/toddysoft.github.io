Die Wartung ist nicht im ersten Jahr enthalten; sie beginnt mit Ihrer Bestellung. Sie ist optional und jährlich verlängerbar, zu 20 % des vollen Listenpreises Ihrer Lizenz.

  • Neue Versionen, neue Funktionen, Verbesserungen und Feinschliff

Ist die Wartung seit mehr als 24 Monaten abgelaufen, kostet der Wiedereinstieg 50 % des aktuellen Listenpreises und enthält 12 Monate Wartung.

Begriffe

Deployment
Eine laufende Instanz eines ToddySoft-Treibers, zum Beispiel in einem Ignition-Gateway, einer VM, auf einem Bare-Metal-Server oder in einem Container. Sie benötigen eine Lizenz pro gleichzeitig laufender Instanz. In einem Docker- oder Kubernetes-Cluster zählt jedes laufende Replikat als Deployment; das Verschieben zwischen Knoten nicht. Ein Hot Standby zählt als Deployment. Beim Autoscaling zählt die höchste Zahl gleichzeitig laufender Replikate.
Standort
Ein physischer Standort oder eine VPC bzw. Region innerhalb eines einzelnen Cloud-Kontos Ihres Unternehmens (zum Beispiel ein AWS-Konto in einer Region).
Plattform
Die Laufzeitumgebung, die das ToddySoft-Modul lädt, zum Beispiel Ignition oder Apache StreamPipes.
Treiber
Ein Protokollmodul wie Beckhoff ADS, Bosch Rexroth ctrlX, EtherNet/IP, Modbus, OPC UA, Schneider Electric UMAS, Siemens S7 und Siemens S7 Web API.

Häufige Fragen

Kann ich einen Treiber vor dem Kauf testen?

Ja. Für jeden einzelnen Treiber gibt es eine kostenlose Testlizenz für einen Monat. Jedes Unternehmen erhält eine Testlizenz pro Treiber und kann bis zu 3 Treiber gleichzeitig testen. Braucht Ihre Evaluierung länger, sprechen Sie uns an. Für die Alle-Treiber-Pakete gibt es keine Testlizenz; testen Sie stattdessen die einzelnen Treiber, die Sie benötigen.

Brauchen Test- und Staging-Systeme eine Lizenz?

Ein Test- oder Staging-System ist ein Deployment wie jedes andere. Zum Evaluieren eines Moduls nutzen Sie die kostenlose Testlizenz. Für ein dauerhaftes Test- oder Staging-System wenden Sie sich an unseren Vertrieb. Eine Standortlizenz deckt alle Testsysteme an diesem Standort bereits ab, da sie dort unbegrenzt viele Deployments erlaubt.

Kann ich eine Lizenz auf neue Hardware umziehen?

Ja, jederzeit. Wenn Sie einen Server ersetzen oder ein Gateway auf eine neue VM umziehen, bleibt die Lizenz gültig. Die Übertragung einer Lizenz an ein anderes Unternehmen, etwa beim Verkauf einer Anlage, bedarf unserer schriftlichen Zustimmung.

Wie funktioniert ein Upgrade auf eine größere Lizenz?

Der bereits bezahlte Betrag wird voll angerechnet. Besitzen Sie drei Deployments eines Treibers und wechseln auf eine Standortlizenz, zahlen Sie den aktuellen Standortpreis abzüglich dessen, was Sie für die drei Deployments bereits bezahlt haben. Das gilt ebenso vom Standort zum Unternehmen, vom Einzeltreiber zu allen Treibern und von einer Plattform zu allen Plattformen. Die Wartung beträgt danach 20 % des vollen Preises der neuen Lizenz.

Wo dürfen die Treiber eingesetzt werden?

Industrielle Protokolle vertrauen dem Netzwerk, in dem sie laufen. Die Treiber dürfen deshalb nicht so eingesetzt werden, dass SPSen oder vergleichbare Geräte von außerhalb Ihrer kontrollierten OT-Umgebung erreichbar werden. Ausgeschlossen sind damit gehostete Dienste, die SPSen über das öffentliche Internet ansprechen, SPS-Verkehr über nicht vertrauenswürdige Netze ohne VPN, MPLS oder gleichwertige Trennung sowie mandantenfähige Dienste, bei denen ein Mandant die SPSen eines anderen erreichen kann.

Darf ich mit den Treibern Leistungen für andere Unternehmen erbringen?

Ja, wenn es Ihre eigene Dienstleistung ist, zum Beispiel die Überwachung oder Wartung von Maschinen bei Ihren Kunden. Nicht erlaubt ist der Weiterverkauf des Zugangs selbst: anderen Unternehmen Datenzugriff oder Konnektivität zu Geräten als Dienstleistung anzubieten. Dafür sprechen Sie uns auf eine Service-Provider-Vereinbarung an.
