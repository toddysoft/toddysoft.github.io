Ignition Modules

Extend Inductive Automation Ignition with ToddySoft's commercial device drivers and modules — bringing additional industrial protocols directly into your SCADA platform.

Ignition Modules by ToddySoft

Ready-to-install modules that plug straight into the Ignition Gateway, giving you connectivity to industrial devices that Ignition does not support out of the box.

Every module is installed as a standard signed Ignition module (.modl) and integrates with Ignition's native tag system — no external gateways or middleware required. Browse symbols, read and write tags, and subscribe to value changes just like you would with any built-in Ignition driver.

Want to try before you buy? Use the button on any module below to request a free trial license or a quote. We'll get back to you with everything you need to get started.

Beckhoff ADS Driver

A native device driver that connects Inductive Automation Ignition directly to Beckhoff TwinCAT PLCs and I/O systems over the ADS protocol. Works with both TwinCAT 2 and TwinCAT 3 devices. Browse symbols, read and write tags, and subscribe to value changes — all from within Ignition. Supports Secure ADS for encrypted and authenticated connections.
